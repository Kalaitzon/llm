 ΟΔΗΓΟΣ SCREENSHOTS

Τα screenshots τεκμηριωνουν την εκτελεση του συστηματος. Παρακατω
ειναι η σειρα που πρεπει να ακολουθησεις και τα ονοματα των αρχειων.

Χρειαζονται ΔΥΟ παραθυρα PowerShell:
  - Παραθυρο Α: τρεχει το honeypot (μενει ανοιχτο)
  - Παραθυρο Β: ολα τα υπολοιπα


----------------------------------------------------------------
 ΒΗΜΑ 0 - Προετοιμασια (μια φορα)
----------------------------------------------------------------
Στο Παραθυρο Β, μεσα στον φακελο LLM_MTE25012:

    pip install -r requirements.txt


----------------------------------------------------------------
 ΒΗΜΑ 1 - Δημιουργια decoys              [decoys_generated.png]
----------------------------------------------------------------
    python 01_generate_decoys.py

Screenshot: το αποτελεσμα "Δημιουργηθηκαν 12 artefacts (7 LLM, 5 manual)".


----------------------------------------------------------------
 ΒΗΜΑ 2 - Εκκινηση honeypot              [honeypot_listening.png]
----------------------------------------------------------------
Στο Παραθυρο Α:

    python 02_ssh_honeypot.py --port 2222

Screenshot: το "Honeypot SSH ακουει στο 127.0.0.1:2222".
ΑΦΗΣΕ ΤΟ ΑΝΟΙΧΤΟ.


----------------------------------------------------------------
 ΒΗΜΑ 3 - Χειροκινητη συνδεση (επιδειξη) [manual_ssh_session_1.png]
                                         [manual_ssh_session_2.png]
----------------------------------------------------------------
Στο Παραθυρο Β:

    ssh -p 2222 root@127.0.0.1

Απαντα "yes", κωδικος: Corp2026!
Μετα δωσε:  whoami
            cat /opt/app/.env
            cat /root/NOTES_infra.md
            exit

Screenshot: ολη η συνεδρια. Δειχνει οτι το honeypot σερβιρει
πραγματικα τα ψευτικα αρχεια (το πιο εντυπωσιακο screenshot).

ΠΡΟΣΟΧΗ: αυτη η χειροκινητη συνδεση ειναι ΜΟΝΟ για το screenshot.
Θα δημιουργησει ενα επιπλεον session στα logs. Γι' αυτο, ΠΡΙΝ το
τελικο τρεξιμο (Βημα 4) καθαριζουμε τα logs, ωστε η αναλυση να
βασιζεται μονο στα 35 playbook sessions.


----------------------------------------------------------------
 ΒΗΜΑ 4 - Καθαρισμα + Playbooks          [playbooks_running_1.png]
                                         [playbooks_running_2.png]
----------------------------------------------------------------
ΠΡΩΤΑ σβησε τυχον προηγουμενα logs (Παραθυρο Β):

    Remove-Item logs\sessions\* -Force
    Remove-Item logs\sessions.jsonl -Force

(Αν το honeypot ειχε κλεισει, ξανατρεξε το Βημα 2 σε καθαρο honeypot.)

Μετα, με το honeypot ανοιχτο, τρεξε ΜΙΑ φορα (Παραθυρο Β):

    python 03_run_playbooks.py --port 2222

Screenshot: η λιστα "[ 1/35] ... [35/35]" και το
"[+] Ολοκληρωθηκαν 35 sessions".


----------------------------------------------------------------
 ΒΗΜΑ 5 - Σταματημα honeypot
